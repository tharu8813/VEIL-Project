New standalone Windows fixture client accepts only a restricted suffix in its own PID-specific local pipe namespace, verifies server PID equals current process, sends only encoded Status, uses identification SQOS, overlapped read/write, shared deadline and cancel event. No retry or wait for arbitrary pipe names; no real broker requests. Reads the first newline-delimited bounded reply (does not prove no later frames), preserves output on failure. CancelIoEx is followed by completion drain for buffer lifetime; not a hard wall-clock guarantee. CI fixture has outer watchdog and tests success, refusal, malformed response, absent pipe, invalid suffix, timeout and cancellation, NOT RUN at commit. Real service identity binding, verified configuration, local pipe provenance, service auth, real broker interoperability, connect timeout, process/session lifecycle and Chromium build/runtime remain unverified. Do not use the synthetic client for product access. Existing WebView2, broker and Rust unchanged. No patch registration or security gate advancement.
