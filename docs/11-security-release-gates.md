# 11. 보안 게이트와 배포 조건

## 운영 정책

VEIL의 보안 기능에는 **미구현 / 구현 / 테스트 완료 / 보안 검증 완료**의 구별이 필수다. UI만 완료된 기능은 보안 검증 완료가 아니다.

검증에 실패한 부분이 있다면 계속 연구용 PoC를 만들 수는 있지만, 사용자의 실제 개인정보를 저장하는 안전한 정식 브라우저로 홍보·배포하지 않는다.

## Gate A. 암호화 저장 및 키 보호 [출시 차단]

- [ ] 민감 영구 데이터 inventory 완성 및 저장 경로 확인
- [ ] 잠금 상태 오프라인 복사에서 키 없이 민감 데이터 복원 불가
- [ ] 키 유도·분리·무결성·백업 포맷 검증
- [ ] 평문 프로필 폴백 불가 확인
- [ ] 임시 경로·로그·캐시·크래시 기록의 위험 범위 확인
- [ ] 잠금은 UI 가리기 이상으로 동작

## Gate B. 데이터 지속성 및 복구 [출시 차단]

- [ ] 영구 쿠키·사이트 데이터 재실행 후 보존
- [ ] 북마크·기록·세션 복원
- [ ] 강제 종료 후 저장소 무결성
- [ ] 비밀번호 분실·키 손상·복구 키 정책 정리
- [ ] 데이터 손실 가능 시 사용자에게 오해 없는 안내

## Gate C. 다운로드 금고 [다운로드 기능 출시 차단]

- [ ] 지원 다운로드 유형이 명시되고 시험되었음
- [ ] 지원 유형에서 원본 평문의 일반 디스크 기록 방지 경로가 검증됨
- [ ] 파일/메타데이터 인증 암호화와 무결성 검사
- [ ] 미지원 유형의 비보호 다운로드 폴백 없음
- [ ] 내보내기·충돌·저장 공간 부족·중단 시나리오 통과

## Gate D. 네트워크 보호 [해당 보호 모드 출시 차단]

- [ ] 표준 모드에서 실제 IP 은닉을 주장하지 않음
- [ ] 보호 모드 경로 강제·DNS·IPv4/IPv6·WebRTC·UDP/QUIC 검증
- [ ] 프록시 중단/절전 복귀 시 직접 연결 폴백 없음
- [ ] 검증 없는 Tor 익명성 주장 금지
- [ ] OS 방화벽 권한 및 제거/복구 절차 검증

## Gate E. 일반 제품 품질 [정식 출시 차단]

- [ ] 표준 브라우저 사용성 및 핵심 단축키 동작
- [ ] 렌더러 샌드박스·보안 업데이트 체계 유지
- [ ] 주요 호환성 회귀 테스트
- [ ] 설치·업데이트·제거·복구 테스트
- [ ] 라이선스 및 공급망 위험 조사
- [ ] 심각도 높은 미해결 보안 결함 없음 또는 공식적으로 출시 보류

## 불합격 처리

- 문서와 `SECURITY_STATUS.md`를 업데이트한다.
- 기능을 안전한 것으로 표시하지 않고 필요하면 기능을 비활성화한다.
- 위험의 정확한 영향과 사용자의 개입이 필요한 지점을 보고한다.
- 보안 요구를 잠정 완화하는 경우 사용자의 명시적 의사결정과 ADR을 요구한다. 단, 안전을 보장할 수 없는 설계를 정식 안전한 제품이라고 주장할 수 없다.

## 릴리스 분류

- **Developer PoC:** 기능/기술 실험용. 실사용 데이터 금지. 보안 보장 없음.
- **Internal Alpha:** 범위를 제한한 내부 시험. 미해결 위험 문서화. 합격 기준·테스터 데이터 범위·알려진 위험은 [ADR-0010](decisions/ADR-0010-internal-alpha.md).
- **Security-qualified Beta:** 명시된 범위의 보안 게이트 통과 및 사용성 회귀 확인.
- **Stable:** 필수 보안·복구·업데이트 게이트와 장기 운영 체계 확립.
