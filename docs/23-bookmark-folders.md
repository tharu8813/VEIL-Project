# 23. 북마크 폴더 (Stage 2-1)

기존 `PageEntry`의 선택적 `FolderId`와 별도 `BookmarkFolders` 목록으로 기존 JSON의 북마크를 그대로 읽는다. 폴더 ID는 GUID, 부모 ID가 없는 항목은 최상위. 순환·누락 부모·중복 ID·16단계 초과는 손상으로 처리하며 프로필을 자동 덮어쓰지 않는다.

- 북마크 관리: 현재 폴더 선택, 폴더 생성/이름 변경/삭제/이동/순서 이동, 북마크 이동/순서 이동. 검색 시 모든 폴더를 대상으로 경로를 표시한다.
- 폴더 삭제는 하위 항목을 상위로 승격하며 북마크를 삭제하지 않는다. 저장 실패 시 두 목록을 함께 복구한다.
- 북마크 바: 최상위 폴더 메뉴 및 최상위 북마크. 각 그룹의 순서를 유지한다. 원격 파비콘 요청 없음.
- Ctrl+D는 기존과 같이 최상위에 추가한다. 중복 URL 정책은 그대로 유지한다.
- HTML 가져오기/내보내기와 드래그 정렬은 별도 후속 작업.

검증: 합성 계층/순환 차단/삭제 보존 smoke 추가. 실제 Windows UI, 폴더 저장·복원·다중 창 및 실패 롤백은 NOT RUN. 보호 저장소/출시 게이트는 변경하지 않는다.

후속 자동화: `p6-bookmark-folders` / `p6-bookmark-folders-read`에서 실제 네이티브 컨트롤로 생성·이름 변경·이동·순서 변경(북마크)·순환 차단·삭제 취소·하위 항목 보존·검색·재시작을 검사하도록 추가했다. Windows 실행은 NOT RUN. 폴더 순서 이동 및 새 폴더의 다중 창 동기화는 별도 검증 대상이다.
