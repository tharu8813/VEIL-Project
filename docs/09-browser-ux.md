# 09. 브라우저 UI/UX 및 사용성 규칙

## 최상위 원칙 [확정]

일반 사용자는 VEIL에서 Chrome/Edge의 기본 사용 경험을 거의 그대로 얻어야 한다. 보안 작업은 자동으로, 확인은 필수일 때만 수행한다.

## 일반 브라우저 기능 체크리스트

- 탭: 새 탭/닫기/이동/순서 변경/닫은 탭 복구/새 창/고정 탭(후속)
- 주소창: 주소 및 검색어 판단, 엔진 선택, 자동완성(개인정보 정책 필요)
- 탐색: 뒤로/앞으로/새로고침/중지/홈/전체화면/확대/페이지 내 검색
- 북마크: 추가/수정/삭제, 폴더 구조, 가져오기/내보내기 정책
- 기록: 검색·삭제·기간 선택
- 다운로드: Ctrl+J, 진행률, 완료/실패, 내부 열기/내보내기
- 사이트 권한: 카메라·마이크·위치·알림·파일 접근 등 최소 권한
- 로그인/사이트 데이터: 자동 보관, 사이트별 삭제, 추적 위험 낮추기
- 설정: 일반/개인정보/다운로드/보안·잠금/고급

## 필수 단축키

| 키 | 동작 |
|---|---|
| Ctrl+T | 새 탭 |
| Ctrl+W | 현재 탭 닫기 |
| Ctrl+Shift+T | 닫은 탭 복원 |
| Ctrl+L | 주소창 포커스 |
| Ctrl+D | 북마크 추가 |
| Ctrl+H | 방문 기록 |
| Ctrl+J | 다운로드 |
| Ctrl+F | 페이지 내 검색 |
| Ctrl+R / F5 | 새로고침 |
| Ctrl+Tab / Ctrl+Shift+Tab | 다음 / 이전 탭 |
| Ctrl++ / Ctrl+- / Ctrl+0 | 확대 / 축소 / 초기화 |

## 사용자 확인 정책

| 상황 | 동작 |
|---|---|
| 탭 이동·검색·탐색·로그인 | 추가 보안 확인 없음 |
| 쿠키/기록/북마크 저장 | 자동 보호 |
| 금고에 파일 다운로드 | 별도 암호화 확인 없음 |
| 지원 형식 파일을 내부 뷰어로 열기 | 일반적으로 추가 확인 없음(콘텐츠 보안은 필수) |
| 잠금 해제·민감 비밀번호 전체 열람 | 사용자 인증 필요 |
| 파일 외부 내보내기 | 사용자 명시적 내보내기 동작 필요 |
| 연결 보호 해제·보안 설정 저하 | 위험을 간결하게 알려주고 명시적 확인 |
| 카메라/마이크 등 사이트 권한 | 표준 브라우저처럼 권한 요청 |

## 다운로드 UX

파일을 클릭하면 별도의 암호화 마법사 없이 다운로드된다. 목록은 일반 다운로드 관리자처럼 보이고, 내부 열기/내보내기/삭제 동작을 제공한다. 외부 열기에서 평문 파일 생성이 필요하면 이를 조용히 숨기지 말고 지원 정책에 맞는 명확한 UX로 처리한다.

## 메시지 설계

- 성공한 보안 동작에는 알림을 과도하게 띄우지 않는다.
- '보안 보호됨'은 실제 검증된 범위에서만 표시한다.
- 오류는 문제·영향·사용자가 할 수 있는 행동의 순서로 설명한다.
- 기술 용어는 고급 상세정보로 이동한다. 예: '파일을 안전하게 저장하지 못했습니다. 다운로드를 중단했습니다.'
- 보안 수준을 낮춰 호환성을 얻는 경우에는 명시적 사용자 동의와 되돌리기를 제공한다.

## 화면 규칙

- Windows의 글꼴 확대/DPI/다크 모드/키보드 접근성/탭 포커스 지원.
- UI 스레드에서 암호화·네트워크 검사·무거운 파일 작업을 실행하지 않는다.
- 설정은 기본적으로 간결하게, 전문 기능은 고급 영역에서 관리한다.
- 개인정보 보호는 사용자에게 부담을 넘기지 않으면서 상태를 오해 없이 보여준다.

## 디자인 완료 판정

보안 기능을 잘 모르는 사용자에게 간단한 사용성 테스트를 수행한다. 설명 없이 검색·로그인·북마크·다운로드·내보내기를 수행할 수 있어야 한다. 보안 경고가 의미 없이 반복되지 않는지 회귀 검사를 한다.
