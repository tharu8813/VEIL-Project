# 01. 제품 요구사항 (PRD)

## 제품 정의

**VEIL**은 Windows에서 Chrome·Edge와 거의 동일한 사용 경험을 제공하면서 사용자 로컬 브라우저 데이터와 다운로드 파일을 암호화해 보호하는 데스크톱 웹 브라우저다.

제품 문구: **Invisible Security, Familiar Experience**.

## 핵심 사용자 경험 [확정]

- 주소창·탭·뒤로/앞으로·새로고침·검색·북마크·기록·다운로드 목록을 익숙한 방식으로 사용한다.
- 사용자가 삭제하지 않은 쿠키, 로그인 유지 데이터, 사이트 저장소, 방문 기록, 북마크, 세션을 재실행 후에도 보존한다.
- 보안 처리 때문에 별도로 ‘암호화’ 버튼을 누르거나, 일상적인 웹 탐색 때마다 확인하는 흐름을 만들지 않는다.
- 정상 보안 동작을 알리는 반복 팝업을 남발하지 않는다.
- 보안/호환성이 충돌할 때 조용히 보안 기능을 끄지 않는다. 한계를 명확하게 보여주고 안전한 대안을 마련한다.

## 필수 기능 요구사항

| ID | 기능 | 요구사항과 수용 기준 |
|---|---|---|
| FR-001 | 웹 탐색 | 주소/검색, 뒤로/앞으로/새로고침, 새 창·탭이 정상 동작한다. |
| FR-002 | 영구 세션 | 정상 종료 및 재실행 후 저장 정책상 유지되어야 할 사이트 데이터가 복원된다. |
| FR-003 | 쿠키 | 영구 쿠키 및 사이트 저장소를 유지하고, 세션 쿠키 정책은 문서화한다. 사이트 서버가 만료시킨 로그인은 보장하지 않는다. |
| FR-004 | 기록 | Ctrl+H에서 방문 기록 조회·검색·삭제. 저장된 기록의 내용은 금고 잠금 시 보호한다. |
| FR-005 | 북마크 | Ctrl+D로 등록, 수정, 삭제 및 재시작 후 복원한다. |
| FR-006 | 비밀번호 | 저장 및 자동완성 지원. 전체 값 열람 시 재인증하고 비밀정보를 별도 보호한다. |
| FR-007 | 다운로드 | 클릭 시 자동으로 금고에 보관하고 Ctrl+J에서 진행률·상태·열기·내보내기를 제공한다. |
| FR-008 | 내보내기 | 명시적 사용자 선택으로만 보호 금고 밖에 평문 파일을 생성한다. 저장 위치·충돌 처리·오류를 처리한다. |
| FR-009 | 잠금 | 초기 설정 후 시작 잠금 해제, 재잠금, 선택적 자동 잠금 지원. 화면 가리기만 하는 가짜 잠금을 금지한다. |
| FR-010 | 네트워크 | 표준 모드에서 HTTPS 우선 및 추적 위험 감소. 프록시/Tor는 별도 검증 후 제공한다. |
| FR-011 | 파일 미리보기 | 지원 형식만 안전하게 브라우저 내부에서 열기. 미지원 형식의 평문 임시 파일 생성 금지. 상세 사양은 후속 설계. |
| FR-012 | 복구 | 크래시·저장소 손상·키 분실 위험과 복구 가능 범위를 명시한다. 암호화 백업 검토. |
| FR-013 | 업데이트 | 브라우저 엔진·보안 패치 업데이트 경로와 릴리스 차단 규칙을 가진다. |
| FR-014 | 사이트 권한 | 카메라/마이크/위치/알림/파일 등 권한을 익숙하게 요청하고 사이트별 관리한다. |

## 비기능 요구사항

- **보안:** 11번 문서의 출시 게이트 통과가 필수다.
- **성능:** 보안 ON/OFF 비교가 아니라, 보호 기능을 적용한 상태와 기본 엔진 구성을 동일 조건에서 계측한다. 임의 성능 수치는 목표로 선언하기 전 측정한다.
- **안정성:** 강제 종료 시 데이터 무결성, 원자적 저장, 복구 오류를 시험한다.
- **접근성:** 키보드 탐색, 포커스, 충분한 대비, 화면 배율, 오류 문구를 검증한다.
- **호환성:** 주요 사이트 유형(로그인/결제/영상/업로드/다운로드) 회귀 테스트를 갖춘다.
- **개인정보:** 필요 이상의 자체 원격 분석, 추적, 클라우드 전송을 기본으로 켜지 않는다.

## 기본 데이터 정책 [확정]

| 데이터 | 기본 정책 |
|---|---|
| 영구 쿠키 | 유지, 암호화 프로필 영역에 저장 |
| 세션 쿠키 | 사이트/브라우저 정책에 맞춰 유지 범위 검증, 장기 복원은 별도 결정 |
| LocalStorage / IndexedDB | 유지, 암호화된 영구 저장 |
| Service Worker / CacheStorage | 호환성 유지, 보호 범위 확인 |
| 방문/검색 기록 | 유지, 보호된 데이터 저장 |
| 북마크/비밀번호 | 유지, 비밀번호 별도 키 보호 |
| 다운로드 파일 | 금고에 암호화 저장 |
| HTTP 캐시 | 메모리 우선 검토, 영구 캐시 여부·용량·보호는 엔진 PoC 후 결정 |
| 일회용 탐색 | 영구 데이터와 격리된 별도 세션(후속 구현) |

## 기본 제공 모드

- **일반 보호 (v1 필수):** 일반 연결, 데이터 영속화, 암호화 금고, HTTPS 우선, 추적 위험 최소화.
- **프록시/VPN 보호 (검증 후):** 명시적으로 설정한 경로에 한정, 연결 실패 시 직접 연결 우회 금지.
- **Tor 익명 모드 (장기):** 프록시 연결만으로 Tor Browser 수준 익명성을 주장하지 않는다.

## 이번 단계에서 범위 제외

모바일, 클라우드 동기화, 자체 VPN 인프라, 사용자용 확장 프로그램 스토어, 복잡한 테마 편집, 다계정 동기화. 필요 시 후속 ADR로 추가한다.

## 제품 수용 테스트 (사용자 관점)

1. 브라우저 설치·첫 실행·잠금 해제 후 일반 웹사이트에 접속할 수 있다.
2. 테스트 사이트 로그인/사이트 데이터/북마크/방문 기록을 만든 뒤 종료·재실행하여 유지 여부를 확인한다.
3. 테스트 PDF를 다운로드해 금고에서 확인하고 선택한 폴더로 내보낸다.
4. 로컬 디스크의 잠긴 저장소에서 의도된 민감 문자열이 평문으로 보이지 않는지 확인한다. 이 검사는 **충분한 보안 증명은 아니며** 별도 추적 테스트를 병행한다.
5. 모든 보안 기능은 `SECURITY_STATUS.md`의 증거가 없는 한 '미검증'으로 표기한다.
