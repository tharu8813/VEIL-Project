## VEIL은 어떤 브라우저인가요?

VEIL은 평소 사용하던 웹 브라우저의 편리함을 유지하면서, 컴퓨터에 남는 개인정보를 더 안전하게 관리하는 것을 목표로 하는 Windows용 브라우저입니다.

시크릿 모드처럼 매번 방문 기록과 로그인 정보를 지우는 대신, 필요한 데이터는 유지하고 브라우저를 사용하지 않을 때 보호하는 방향으로 개발하고 있습니다. 복잡한 보안 설정 없이 일상적인 웹 탐색을 할 수 있도록 만드는 것이 목표입니다.

## 주요 기능

| 기능 | 어떤 점이 달라지나요? |
| --- | --- |
| 익숙한 브라우징 | 탭, 검색, 북마크, 방문 기록, 닫은 탭 복원 등 일반 브라우저의 기본 기능을 제공합니다. |
| 개인정보 보호 프로필 | 로그인에 쓰이는 쿠키와 사이트 데이터, 방문 기록 등을 유지하면서 잠긴 저장 공간에서 보호하도록 개발하고 있습니다. |
| 다운로드 금고 | 지원되는 다운로드를 암호화된 금고에 보관하고, 필요할 때 사용자가 직접 외부로 내보낼 수 있도록 합니다. |
| 안전한 연결 | HTTPS 우선 연결, 추적 방지, 보안 DNS 및 별도의 프록시 보호 모드를 개발하고 있습니다. |
| 위협 보호 | SmartScreen 설정과 위험한 사이트·파일을 확인하는 자체 위협 검사 기능을 개발하고 있습니다. 자체 검사에 필요한 출시용 목록은 아직 준비되지 않았습니다. |

일부 기능은 개발 환경과 가상 머신에서 시험 중이며, 모든 웹사이트나 다운로드 방식이 지원되는 것은 아닙니다.

## 다운로드 및 지원 환경

**현재 다운로드할 수 있는 정식 설치 파일은 없습니다.** 첫 공개 버전이 준비되면 [Releases](https://github.com/tharu8813/VEIL-Project/releases)에서 확인할 수 있도록 할 예정입니다.

- 지원 예정 운영체제: Windows 11 (64비트)
- 기본 사용자 인터페이스: 한국어
- 현재 개발 버전: Microsoft Edge WebView2 기반

## 개인정보 보호에 관하여

VEIL은 VPN이나 익명 브라우저를 대체하지 않습니다. 웹사이트와 인터넷 제공업체에 대한 완전한 익명성을 보장하지 않으며, 잠금 해제 중인 컴퓨터의 악성코드나 사용자가 외부로 내보낸 파일까지 보호할 수 있는 것은 아닙니다.

저장 데이터의 암호화, 다운로드 보호, 네트워크 보호 및 설치·업데이트의 안전성을 검증한 뒤 공개 배포를 진행할 예정입니다.
